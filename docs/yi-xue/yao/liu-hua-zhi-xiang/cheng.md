# 承
“承”有承上启下、支撑的意思。

“九”代表“阳爻”，“六”代表“阴爻”。

有三种情况

## 情况一
在一个六爻卦中，若阳爻在上，阴爻在其下，则此阴爻对于上面的阳爻来说，称为*承*。

例如：水火未济卦（䷿）。九二爻阳爻在上，初六爻阴爻在其下。故初六爻对九二爻来说，可称承。即初六爻承九二爻。简称为“初承二”。

同理，这个卦中除了初承二还有三承四、五承上。

见到“初承二”之辞，就可以知道二爻是个阳爻；初爻是个阴爻；阴爻在阳爻的下面；阴爻支撑着上面的阳爻。

即阴爻对阳爻给予帮助、赞助、支援。

## 情况二
在一个六爻卦中，若是一个阴爻在下，数个阳爻在上，则下面的这个阴爻对于上面的数个阳爻来说，均可称“承”。

例如：天风姤卦（䷫）。只有最下面的初六爻是一个阴爻，其余的五个爻都是阳爻。所以初六爻对它上面的这五个阳爻来说均可称**承**。即初六爻承九二爻、初六爻承九三爻、初六爻承九四爻、初六爻承九五爻、初六爻承上九爻。简称初承二、初承三、初承四、初承五、初承上。

## 情况三
在一个六爻卦中，一个阳爻在上，数个阴爻连接在其下。则下面的这数个阴爻对于上面这个阳爻来说，均可称**承**。

例如：地山谦卦（䷎）。九三爻是个阳爻。初六爻及六二爻都是阴爻，并都在九三阳爻之下。则初六爻和六二爻对于其上面的这个九三爻阳爻来说，均可称承。即初六爻承九三爻、六二爻承九三爻。简称初承三、二承三。
