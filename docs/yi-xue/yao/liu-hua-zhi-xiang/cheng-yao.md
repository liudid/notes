# 乘
乘即乘虚而入的意思。乘你不备、倒霉、不行的时候占到你头上去。

乘有两种情况

## 情况一
一个六爻卦中，若阴爻在上，阳爻在下。则此阴爻对于下面的阳爻来说，称为“**乘**”。

阴的应该在下面，阳的应该在上面。乾为天，天应该在上。地为坤，地应该在下。现在却是阳爻在下，阴爻在上，这是本末倒置的现象。是乘阳之虚而阴入之状态。

例如：水地比卦。在《杂卦传》中曰：比乐，师忧。遇到比卦往往都是高兴的事情。

在这个比卦中，九五爻是阳爻，上六爻是阴爻。即阴爻在阳爻之上。故上六爻对下面的九五爻可以称乘。即上六爻乘九五爻，简称上乘五。

从卦上讲，这两个爻虽然性质相反，可是他们却都各在其位上————“当位”了。这样就使不（吉）利的状况有所改善。骑在九五之尊上头并可干扰其权势的应该是谁呢？指的是不该发生的事发生了。

这里的“乘”与“承”的意思正好相反。


## 情况二
一个六爻卦中，接连排列的几个阴爻都在一个阳爻上面。则这几个阴爻对下面的阳爻都可称“乘”。

例如：地山谦卦。九三爻是阳爻，其六四、六五、上六爻，都是阴爻，且都处在九三爻的位置之上。所以说九三爻上面的任何一个阴爻都可以对九三爻称乘。

也就是说，六四爻乘九三爻、六五爻乘九三爻、上六爻乘九三爻。简称四乘三、五乘三、上乘三。

所以在解谦卦中九三爻的爻辞时说：自四以上乘阳。

意思就是说，从第四个爻及以上的这些爻都乘阳。他们都乘九三阳爻之危，占据了其上的位置并欺压它。这是一种很被动的局面。

注：这种事物的好坏之分，要看对谁来说。如果是平头百姓那是好事，如果你是个厂长那就是不利的。
