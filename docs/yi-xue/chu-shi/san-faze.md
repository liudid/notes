# 三个法则
宇宙的万事万物——人生也好，情绪也好，思想也好……都有它的原则和道理。

宇宙间的任何一个现象，也一定有它的理，同时每个现象，又一定有它的数。

同一个易的结构，可以从理、象、数三个角度观察。

理 → 象 → 数

但不能把它理解成简单的时间先后。

不是说：先出现理，过一会儿出现象，再过一会儿出现数。而是：同一个结构，在不同认知层面上的显现。

## 理（义理）（为什么会这样，既阴阳变易的法则）
阴阳为什么能够如此变化，以及万物变化为什么具有一定的规律和结构。比如：阳极则阴生，阴极则阳生。这不是一个具体的“象”，也不是一个数字。它是在说变化本身的原则。

## 象（卦象）（变化呈现出来是什么，既天地及万物的模型）
“象”是一个结构的显现方式，象是“理”的显示器，把抽象的理变成可视画面。比如乾卦所代表的结构，可以在“天”这个现象中得到呈现。“天”就是乾卦所代表的结构呈现的象。

## 数（筮数）（这种结构如何表达、定位，即变化的尺度与周期）
事物变化过程中所遵循的数量关系、时间节点和度量标准。


::: info
打个比方：春天播种，秋天收获。

- 理：是“春生秋杀”的自然规律。

- 象：是种子发芽、枝叶茂盛、果实累累的直观画面。

- 数：是生长周期（三个月、一百天），以及适宜的温度湿度数值。
:::

::: info
例如一个卦。

你看到它的阴阳爻：

这是象。

你发现它有三爻：

这是数。

你进一步理解为什么这三个爻会形成这样的阴阳关系：

这是理。

所以实际上：

数可以显象，象可以明理，理可以统摄象数
:::
